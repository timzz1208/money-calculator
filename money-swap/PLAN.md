# 錢在工作｜製作計畫

IG 9:16 短片，巨大石碑字塊配合重低音砸落，最後「你」和「錢」互換位置。
音樂：REVENGE (Super Slowed)，使用歌曲 21.0–52.2 秒（影片 31.2 秒）。

## 已定案

| 項目 | 決定 |
|---|---|
| 文案 | 鉤子「你以為你在賺錢？」→ 你在工作／錢在睡覺 → 月薪 45,000／月底剩 3,200 → 「你」「錢」互換 → 讓錢去上班 |
| 做法 | 混合 2.5D：Blender 算寫實石碑圖，2D 做動畫、震動、特效、後製 |
| 字型 | 思源宋體 Black（刻字石碑） |
| 美術 | 石碑廣場：炭灰冷調暗部、骨白石碑、朱紅描紅、暖色火星；底片顆粒、暗角 |
| 震動 | 三級：每拍微震／字塊落地重震／爆發與互換最大震動，強度跟著實際重低音 |
| 聲音 | 歌在 IG 內加入；影片只含少量效果音（龜裂、崩落、巨石上升、撞擊、印章） |
| 輸出 | 1080×1920、30fps＋動態模糊 |

## 步驟

- [x] 1. 拍點地圖：從歌曲抓出 21.0–52.2 秒每一拍的時間與強度、斷拍、爆發、缺拍、過門 → `beats.json`
- [x] 2. 動態骨架：2D 動畫引擎（字塊砸落、三級震動、動態模糊、揚塵、碎石、衝擊、互換），先用暫代字塊
- [x] 3. 節奏預覽：低解析度影片疊上歌曲，檢查每一下震動是否對拍（歌只用於預覽，不進 repo）
- [x] 4. 石碑素材：Blender 以思源宋體建模刻字石碑，每個字算一張透明背景圖；朱紅描紅版
- [x] 5. 美術合成：背景、光束、霧、地面、調色、顆粒；換上正式石碑，輸出 3 張關鍵定格
- [x] 6. 效果音：合成 5–6 個點綴音效，壓在音樂下方
- [x] 7. 正式輸出：1080×1920 30fps 動態模糊；影片只含效果音，另附一版含歌的預覽
- [x] 8. 交付：推送到 repo、下載連結、IG 上傳說明（選歌起點 0:21、音量比例）

## 驗收節點

1. 節奏預覽（步驟 3）
2. 三張關鍵定格（步驟 5）
3. 完整影片（步驟 8）

## 備案

- Blender 太慢或無法運作 → 改用 three.js 算高品質靜態石碑圖，再疊 2D 後製
- IG 音樂庫的版本時間不同 → 依 IG 的起點秒數重新對齊

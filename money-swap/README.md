# 錢在工作

IG Reels 9:16 短片：巨大石碑字塊配合重低音砸落，最後「你」和「錢」互換位置。
音樂 REVENGE (Super Slowed) 在 IG 內加入，影片本身只含少量效果音。

| 檔案 | 用途 |
|---|---|
| `money-swap-ig.mp4` | 成品：31.2 秒、1080×1920、30fps＋動態模糊，只含效果音（上傳這個） |
| `video.html` | 動畫原始檔；瀏覽器打開可預覽、拖曳時間軸 |
| `timeline.js` | 每個字塊出場、互換、崩落的時間點（取自實際拍點） |
| `beats.py` → `beats.json`／`beats.js` | 從歌曲抓出每一拍的時間與重低音強度 |
| `tiles.py` → `tiles/*.png` | Blender 算的刻字石碑（思源宋體 Black，高度圖推出真實刻痕） |
| `sfx.py` → `sfx.wav` | 點綴效果音：龜裂、崩落、巨石上升、撞擊、印章 |
| `render.js` | 逐格輸出 MP4 |
| `PLAN.md` | 製作計畫與進度 |

歌曲檔只在本機用來對拍，已用 `.gitignore` 排除，不在 repo 裡。

## 上傳 IG

1. 上傳 `money-swap-ig.mp4`。
2. 加入音樂：搜尋 **REVENGE (Super Slowed)**，要選**同一個版本**（原速版或其他版本的時間點不同）。
3. 把歌曲片段的起點拉到 **0:21**。影片第 4 秒鉤子碎裂時，應該剛好是歌曲重低音全面爆發的那一下。
4. 音量：音樂 100%，原始音訊（效果音）約 **40%**。
5. 封面：選第 2～3 秒（「你以為你在賺錢？」出現裂痕的畫面）。

如果 IG 上找不到同一個版本，或起點對不上，把 IG 上那首歌的名稱和你選的起點告訴 Claude，重新對齊時間軸即可。

## 畫面震動

依實際重低音強度驅動，分三級：

| 等級 | 時機 | 效果 |
|---|---|---|
| 1 | 每一拍 | 輕微下沉震動、亮度微閃 |
| 2 | 字塊落地 | 明顯往下衝擊再彈回、揚塵、碎石、色彩錯位 2 格 |
| 3 | 爆發、互換落下 | 最大震動加旋轉、白光、衝擊波、大量碎石 |

## 重新製作

```bash
pip install bpy fonttools skia-pathops pillow scipy numpy imageio-ffmpeg
python3 beats.py 歌曲.mp3                          # 拍點
python3 tiles.py NotoSerifTC.ttf                   # 石碑（約 8 分鐘）
python3 sfx.py sfx.wav                             # 效果音
SERIF_TTF=NotoSerifTC.ttf FONT_TTF=NotoSansTC.ttf FFMPEG=ffmpeg \
  node render.js --mb 4 --fps 30 --sfx sfx.wav --vbitrate 9M --out money-swap-ig.mp4
# 只看幾張定格：node render.js --mb 4 --frames 2.6,16.5,21.52
```

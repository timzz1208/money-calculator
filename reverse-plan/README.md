# 逆向財務工程

IG Reels 9:16 教育動畫：先寫下想要的生活與每月現金流，再往回拆收入來源、行動數字與風險備援。
依「動畫製作 AI 交接包」與 IG 輪播腳本製作，部分調整見下方。**目前是預覽版，不是最終發布版。**

| 檔案 | 用途 |

| `reverse-plan-clean.mp4` | 無字版：同一支片拿掉所有字卡與數字，給後製自己疊字 |

## 視覺方向：一張從終點往回畫的地圖

- 照交接包：奶油紙底、深海軍藍字、暖黃色數字、珊瑚紅只用在行動與警示
- 全片是一張大地圖，八幕放在地圖上不同位置。換幕時鏡頭沿著一條珊瑚紅虛線**往左、往回**走，把「逆向」直接畫出來
- 紙紋與格線是靜態圖樣，跟著鏡頭移動；沒有逐格顆粒，檔案小
- 卡片一律深藍描邊＋平面錯位陰影，像編輯插畫；不用發光、漸層
- 字型：思源黑體（Noto Sans TC）＋ Roboto 數字

## 和交接包不同的地方

- 交接包要求字卡由後製處理，是為了避免生圖模型產生假字。這裡全部是程式畫的，字不會錯，所以直接做了含字版；另附無字版給想自己排字的人
- 第一幕沒有畫人物，用「在選項間跳來跳去的選擇框」表現猶豫，人物用程式畫容易顯得廉價
- 定義那一幕用五站（生活、現金流、收入、行動、備援），對齊字卡的五個詞
- 壓力測試第 1 題不顯示「撐幾個月」的數字，因為腳本沒有提供，不自行補

## 內容邊界（已檢查）

- 40,000、10,000、10,000、60,000、15,000、4、20%、20 都沒改，並標示「示意」
- 20% 標示為示意假設，不是市場平均
- 沒有商品名、報酬率、保證、翻倍、財富自由等字眼
- 片尾聲明：一般資訊整理，不構成投資、保險或個人化財務建議
- 公開前請依所屬公司的審核流程確認

## 重新輸出

需要 Node + Playwright（Chromium）與 ffmpeg；字型放在同一個資料夾：
`sans500.ttf`、`sans700.ttf`、`sans900.ttf`（Noto Sans TC）、`roboto500.ttf`、`roboto700.ttf`（Roboto）。

```bash
FONT_DIR=/path/to/fonts node render.js --frames 0,20,70        # 只輸出幾張定格
FONT_DIR=/path/to/fonts node render.js --vbitrate 3M           # 預覽版
FONT_DIR=/path/to/fonts node render.js --clean --vbitrate 2.5M # 無字版
```

畫面完全由時間決定，同一秒永遠輸出同一格。修改時用秒數下指令即可，例如「27.0 秒的第一塊積木晚 0.3 秒落下」。
